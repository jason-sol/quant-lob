### Crossed rows

The gate prints `crossed_pre_open`, `crossed_regular` and `crossed_post_close`. A row counts as crossed when both sides are present and best bid >= best ask, so locked rows count too.

| Session | AAPL | MSFT | SPY |
|---|---:|---:|---:|
| Before 09:30 | 0 | 0 | 0 |
| 09:30 to 16:00 | 0 | 0 | 0 |
| After 16:00 | 0 | 0 | 0 |

Zero crossed rows only means something if the rows are two-sided with tight spreads, so a bid/ask swap would show up. They are:

```sh
build/release/qlob_replay data/<SYM>-20190130.itch --depth 1 --snapshots - 2>/dev/null | awk -F, 'NR>1 {
  s = ($2<34200000000000) ? "pre" : ($2<57600000000000) ? "regular" : "post"; n[s]++
  if ($3 && $5) { two[s]++; d=$5-$3; if (!(s in min) || d<min[s]) min[s]=d } }
  END { for (s in n) print s, "rows=" n[s], "two_sided=" two[s], "min_spread=" min[s] }'
```

## External price anchor

Both implementations were written from the same layout table, so a shared price-scaling error would still pass the diff. The anchor checks prices against an outside source.

```sh
uv run --project tools python -m qlob_tools.anchor data/<SYM>-20190130.itch
build/release/qlob_replay data/<SYM>-20190130.itch --depth 1 --snapshots - 2>/dev/null \
  | awk -F, 'NR>1 && $2<=57600000000000' | tail -1 | awk -F, '{printf "%s mid=%.4f\n", $0, ($3+$5)/20000}'
```

Source for the official close: Yahoo Finance daily chart data for 2019-01-30, fetched 2026-10-12.

```sh
curl -s -A "Mozilla/5.0" "https://query1.finance.yahoo.com/v8/finance/chart/AAPL?period1=1548806400&period2=1548979200&interval=1d"
curl -s -A "Mozilla/5.0" "https://query1.finance.yahoo.com/v8/finance/chart/MSFT?period1=1548806400&period2=1548979200&interval=1d"
```

- MSFT: the first `close` value is 106.38.
- AAPL: the first `close` value is 41.3125. Yahoo's `close` field is adjusted for splits, and Apple split 4-for-1 on 2020-08-31, so the close as traded was 41.3125 × 4 = 165.25.
- The `close` field is not adjusted for dividends. The `adjclose` field is, and wasn't used.

For Nasdaq-listed stocks, the official close is the Nasdaq Closing Cross price, so an exact match is expected.

SPY is listed on NYSE Arca, so its official close comes from Arca and SPY is skipped for this anchor. The anchor command still finds Nasdaq's own crosses for SPY in the file: an opening cross of 0 shares at price 0, and a closing cross of 500 shares at 267.4400.

## Wall-clock

Informational, not a benchmark. M2 benchmarks run on Linux x86. These runs were on an Apple-silicon Mac, some with other work running at the same time. Each time is the `real` line of `/usr/bin/time -p <command>`, using the commands above.

The gate's wall-clock is set by the Python reference, since the C++ side runs alongside it and finishes first.
