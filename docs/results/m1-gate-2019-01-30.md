## Differential gate (depth 10)

```sh
uv run --project tools python -m qlob_tools.gate data/<SYM>-20190130.itch --depth 10 --replay build/release/qlob_replay
```

This is the strict gate (no `--allow-anomalies`). `GATE PASS` requires all of:

- zero Snapshot mismatches between the Reference Book and the C++ Book
- identical values for every counter both sides report
- every anomaly counter at 0: `unknown_order_refs`, `duplicate_order_refs`, `zero_qty_adds`, `excess_reductions`, `decode_rejects`, `trailing_bytes`
- no crossed rows from 09:30 to 16:00
- `exec_not_at_front` at 0 (C++ only; see [Queue priority](#queue-priority))

Counter meanings:

- `excess_reductions`: an Execute or Cancel for more shares than the order has resting. The order is removed.
- `decode_rejects`: a book-type Frame (A, F, E, C, X, D, U) that fails to decode, from a wrong length or an invalid side. It produces no row and is not counted in `events`.
- `exec_not_at_front`: an E execution against an order that is not first in its Price level's queue.
- `exec_with_price_not_at_front`: the same check for C executions. Reported, not gated.

## Queue priority

Within a Price level, Nasdaq ranks orders by Order Reference Number, which it assigns when it receives the order. The order in which Add messages arrive in the feed is usually the same, but not always.

The Book first queued each Price level by Add-message arrival. With that ordering, E executions hit an order that was not at the front of its queue 927 times in AAPL, 120 in MSFT and 0 in SPY.

The difference comes from the Opening Cross. Market Hours orders entered before the open take part in the cross, and whatever is left afterwards is published with A messages. Each of those orders keeps the reference it got on entry. Counting Add messages whose reference is lower than one already seen gives 37,981 for AAPL, 19,799 for MSFT and 36 for SPY, all between 09:30:00 and 09:30:32.

The Book now queues each Price level by Order reference. `exec_not_at_front` is then 0 on all three symbols, and the gate fails if it is not.

Order Executed With Price (C) messages hit an order behind the front 187 times in AAPL, 1,058 in MSFT and 4,318 in SPY, with either ordering. All but one execute one tick ($0.01) better than the resting order's displayed price. The exception, in SPY, is $0.005 better. Orders ranked at a non-displayed price behave this way (Price to Comply and Post-Only orders), so this count is reported and not gated.

This script reproduces every count in this section. It doesn't use the C++ Book. It replays one extract with two queues per Price level, one by arrival and one by reference:

```sh
uv run --project tools python - data/<SYM>-20190130.itch <<'EOF'
import bisect, sys
from collections import Counter
from qlob_tools.framing import FrameStream
from qlob_tools.ref_book import Add, Cancel, Delete, Execute, Replace, decode

orders, by_arrival, by_ref, out = {}, {}, {}, Counter()
late_adds, non_printable, top_ref = [], [], 0

def add(ref, side, px, qty):
    orders[ref] = [side, px, qty]
    by_arrival.setdefault((side, px), []).append(ref)
    bisect.insort(by_ref.setdefault((side, px), []), ref)

def remove(ref):
    side, px, _ = orders.pop(ref)
    by_arrival[side, px].remove(ref)
    by_ref[side, px].remove(ref)

for _, msg in FrameStream(open(sys.argv[1], "rb")):
    ev = decode(msg)
    if isinstance(ev, Add):
        if ev.ref < top_ref:
            late_adds.append(ev.ts)
        top_ref = max(top_ref, ev.ref)
        add(ev.ref, ev.side, ev.price, ev.shares)
    elif isinstance(ev, Replace):
        top_ref = max(top_ref, ev.new_ref)
        side = orders[ev.orig_ref][0]
        remove(ev.orig_ref)
        add(ev.new_ref, side, ev.price, ev.shares)
    elif isinstance(ev, Delete):
        remove(ev.ref)
    elif isinstance(ev, (Execute, Cancel)):
        side, px, _ = orders[ev.ref]
        if isinstance(ev, Execute):
            kind = "E" if ev.price is None else "C"
            out[f"{kind}_not_at_front_by_arrival"] += by_arrival[side, px][0] != ev.ref
            out[f"{kind}_not_at_front_by_ref"] += by_ref[side, px][0] != ev.ref
            if kind == "C" and by_ref[side, px][0] != ev.ref:
                out[f"C_better_than_display_by={(ev.price - px) * (1 if side == 'B' else -1)}"] += 1
                if ev.printable == "N":
                    non_printable.append(ev.ts)
        orders[ev.ref][2] -= ev.shares
        if orders[ev.ref][2] <= 0:
            remove(ev.ref)

for k, v in sorted(out.items()):
    print(f"{k}={v}")
print(f"late_adds={len(late_adds)} first_ns={min(late_adds)} last_ns={max(late_adds)}")
print(f"C_non_printable={len(non_printable)} first_ns={min(non_printable, default=0)} last_ns={max(non_printable, default=0)}")
EOF
```

Prices are in units of $0.0001, so `C_better_than_display_by=100` is one tick. Timestamps are nanoseconds after midnight Eastern; 09:30:00 is 34,200,000,000,000.

- MSFT: the first `close` value is 106.38.
- AAPL: the first `close` value is 41.3125. Yahoo's `close` field is adjusted for splits, and Apple split 4-for-1 on 2020-08-31, so the close as traded was 41.3125 × 4 = 165.25.
- The `close` field is not adjusted for dividends. The `adjclose` field is, and wasn't used.

For Nasdaq-listed stocks, the official close is the Nasdaq Closing Cross price, so an exact match is expected.

SPY is listed on NYSE Arca, so its official close comes from Arca and SPY is skipped for this anchor. The anchor command still finds Nasdaq's own crosses for SPY in the file: an opening cross of 0 shares at price 0, and a closing cross of 500 shares at 267.4400.
