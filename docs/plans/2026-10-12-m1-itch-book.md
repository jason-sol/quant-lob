# M1 ITCH Book Implementation Plan

Status: implemented; results in docs/results/m1-gate-2019-01-30.md.

**Goal:** A C++20 Book replays a single-symbol Extract of a public Nasdaq ITCH 5.0 day file. Its Snapshots must be identical to an independent Python Reference Book, with zero unknown-order Events and an external price anchor.

**Architecture:**
- `feed/itch` validates and decodes length-prefixed big-endian ITCH frames into `qlob::Event`.
- `book` applies Events. In M1 it uses std containers on purpose: this is the baseline M2 benchmarks against.
- `qlob_replay` streams Snapshot CSV.
- Python `tools/` (`qlob_tools`) encodes fixtures, extracts symbols from a day file, runs the Reference Book, and streams a row-by-row comparison against `qlob_replay`, with no intermediate CSVs on disk.

**Tech Stack:**
- C++20, CMake ≥ 3.25, Ninja, GoogleTest (FetchContent), ASan/UBSan (Apple clang; LeakSanitizer is unavailable on macOS arm64).
- Python 3.12, uv, hatchling, pytest.
- GitHub Actions.

**Spec:** `docs/specs/2026-10-11-quant-lob-design.md` (Goals 1–2). Use the terms in `UBIQUITOUS_LANGUAGE.md`.

**Branches:** one per work group, named as given. Each "Commit checkpoint" step marks a commit boundary.

## Reference: ITCH 5.0 (verified against NQTVITCHspecification.pdf)

All integers are big-endian. Every message in a file is preceded by a 2-byte big-endian length. Offsets count from the message type byte.

**Common header:**

| Offset | Field |
|---|---|
| 0 | type |
| 1–2 | stock locate (u16) |
| 3–4 | tracking number (u16) |
| 5–10 | timestamp, ns since midnight (u48) |

**Book messages:**

| Type | Len | Body |
|---|---|---|
| `A` add | 36 | 11–18 ref (u64), 19 side `B`/`S`, 20–23 shares (u32), 24–31 stock, 32–35 price (u32, 4 dp) |
| `F` add with MPID | 40 | as `A`, plus 36–39 attribution |
| `E` executed | 31 | 11–18 ref, 19–22 executed shares, 23–30 match number |
| `C` executed with price | 36 | 11–18 ref, 19–22 shares, 23–30 match, 31 printable, 32–35 price. The price can differ from the display price; the Book ignores it. |
| `X` cancel | 23 | 11–18 ref, 19–22 cancelled shares |
| `D` delete | 19 | 11–18 ref |
| `U` replace | 35 | 11–18 original ref, 19–26 new ref, 27–30 shares, 31–34 price. The side is retained from the original. |

**Expected lengths for all types**, used for validation. Any other type byte is `unknown_type`:

|---|---|
| S | 12 |
| R | 39 |
| H | 25 |
| Y | 20 |
| L | 26 |
| V | 35 |

**`Q` cross trade (40):**

| Offset | Field |
|---|---|
| 11–18 | shares (u64) |
| 19–26 | stock |
| 27–30 | cross price |
| 31–38 | match number |
| 39 | cross type (`O` open, `C` close, `H` IPO/halt) |

Stock locate codes are unique per day and never reused intraday, so filtering by locate is valid. `P`, `Q` and `B` don't change the displayed Book.

## Semantics both implementations must share

These rules are specified up front so the C++ Book and the Reference Book can't diverge silently.

- **Prices** are raw `u32` integers (4 implied dp) everywhere, including CSV. Never use floats.
- **One Snapshot row per decoded book Event** (`A`, `F`, `E`, `C`, `X`, `D`, `U`), including Events with unknown refs. `seq` is a 0-based index over decoded book Events.
- **Unknown ref** on `E`, `C`, `X`, `D` or `U`: increment `unknown_order_refs` and leave the Book unchanged. For `U`, the new order is *not* added.
- **Duplicate ref** on `A`, `F` or `U`'s new ref, when the id is already live: increment `duplicate_order_refs` and ignore the Event.
- **Zero-quantity Add or Replace**: increment `zero_qty_adds` and ignore the Event.
- **Check order** for Add/Replace: ref checks (unknown original, duplicate new id) first, then zero quantity. A zero-qty Add on a live id counts as a duplicate only. A Replace whose new id equals its (live) original id is a duplicate.
- **Over-execution or over-cancel** (shares > resting): increment `excess_reductions` and remove the order.
- **Decode rejects:** a frame with a book message type that fails to decode (wrong length, invalid side byte) increments `decode_rejects`; it produces no row and is not counted in `events`.
- **Counters compared across both sides:** `events`, `decode_rejects`, `unknown_order_refs`, `duplicate_order_refs`, `zero_qty_adds`, `excess_reductions`. Any difference fails the gate.
- **Frame validation (`--count` / `scan`)**: `count_<T>` counts every non-empty frame by its type byte, including unknown types (which also increment `unknown_type`). `first_bad_offset` is the length-prefix offset of the first *complete* frame that is empty, unknown-type or length-mismatched. A truncated final frame is reported only via `trailing_bytes`.
- **Queue priority** within a price level is by Order Reference Number (assigned at receipt), not by Add-message arrival: orders entered before the open are published after the Opening Cross yet keep their earlier refs. An out-of-sequence Add is inserted in ref order; a Replace takes its new ref (back of the queue); a partial Cancel keeps its position.
- **FIFO check**: `exec_not_at_front` counts `E` executions whose order is not first in its level's ref-ordered queue; the strict gate requires 0. `C` executions fill at a price different from their display price (Price to Comply / Post-Only orders ranked at a non-displayed price), so they are reported separately as `exec_with_price_not_at_front` and never gate.
- **Same-timestamp bursts** (for example several `E` then an `A`) produce intermediate Snapshots. That's harmless here; note it for BBO metrics in M3.

- [ ] **Step 5: Implement `itch.hpp` / `itch.cpp`.**

```cpp
// itch.hpp
#pragma once
#include <array>
#include <cstddef>
#include <cstdint>
#include <optional>
#include <span>
#include "qlob/event.hpp"

namespace qlob {
std::optional<Event> decode(std::span<const std::byte> msg);  // nullopt: empty, non-book, wrong length
std::size_t expected_length(unsigned char type);              // 0 = unknown type

struct FrameStatus { std::size_t trailing_bytes = 0; };

template <class F>
FrameStatus for_each_frame(std::span<const std::byte> buf, F&& on_msg) {
  std::size_t pos = 0;
  while (pos + 2 <= buf.size()) {
    const auto len = (std::to_integer<std::size_t>(buf[pos]) << 8) |
                     std::to_integer<std::size_t>(buf[pos + 1]);
    if (pos + 2 + len > buf.size()) break;
    on_msg(buf.subspan(pos + 2, len), pos);
    pos += 2 + len;
  }
  return {buf.size() - pos};
}

struct FrameReport {
  std::array<std::uint64_t, 256> counts{};
  std::array<std::uint64_t, 256> length_mismatch{};
  std::uint64_t unknown_type = 0, empty_frames = 0;
  std::size_t first_bad_offset = SIZE_MAX;
  std::size_t trailing_bytes = 0;
};
FrameReport scan(std::span<const std::byte> buf);  // counts + validation, no decoding
}  // namespace qlob
```

  - `on_msg` takes `(msg, offset)`.
  - `itch.cpp` uses `be(p, n)` (big-endian read of n ≤ 8 bytes) and a 256-entry `constexpr` expected-length table.
  - `decode` returns `nullopt` when the message is empty or its length doesn't match the table.

```cpp
// book.hpp
#pragma once
#include <cstddef>
#include <cstdint>
#include <functional>
#include <list>
#include <map>
#include <unordered_map>
#include <vector>
#include "qlob/event.hpp"

namespace qlob {
struct LevelView { Price price = 0; std::uint64_t qty = 0; };
struct Snapshot { std::vector<LevelView> bids, asks; };
struct BookStats {
  std::uint64_t events = 0, unknown_order_refs = 0, duplicate_order_refs = 0, excess_reductions = 0;
};

class Book {
 public:
  void apply(const Event& ev);
  Snapshot snapshot(std::size_t depth) const;
  bool crossed() const;
  void check_invariants() const;  // throws std::logic_error; always compiled, used by tests
  const BookStats& stats() const { return stats_; }

 private:
  struct Resting { OrderId id; std::uint32_t qty; };
  struct Level { std::uint64_t total = 0; std::list<Resting> fifo; };
  struct Locator { Side side; Price price; std::list<Resting>::iterator it; };

  void add(OrderId id, Side side, std::uint32_t qty, Price price);
  void reduce(OrderId id, std::uint32_t qty);
  void remove(OrderId id);

  std::map<Price, Level, std::greater<>> bids_;
  std::map<Price, Level> asks_;
  std::unordered_map<OrderId, Locator> orders_;
  BookStats stats_;
};
}  // namespace qlob
```

  Follow the shared semantics above.
  - `crossed()` is `!bids_.empty() && !asks_.empty() && bids_.begin()->first >= asks_.begin()->first`.
  - Removal looks up the level by `Locator::price`, which is O(log L). This is deliberate: it's the baseline cost M2 removes.

### Task 5: `qlob_replay`

- [ ] **Step 1: Usage.** `qlob_replay <file> [--depth N] [--snapshots <path>|-] [--count]`.
  - **Reading:** mmap the file read-only.
  - **`--count`:** calls `scan()` and prints `count_<T>=N` for each type with N > 0, plus `length_mismatch_<T>=N`, `unknown_type`, `empty_frames`, `first_bad_offset` and `trailing_bytes`. Output is one per line, sorted by key, on stdout.
  - **Default mode:** for each frame, decode and apply. With `--snapshots`, write the header `seq,ts_ns,bid_px1,bid_qty1,ask_px1,ask_qty1,...` and then one row per decoded book Event. `-` means stdout.
  - **End-of-run counters:** written to stderr as sorted `key=value` lines: `events`, `unknown_order_refs`, `duplicate_order_refs`, `excess_reductions`, `trailing_bytes`.
  - **Exit codes:** 0 on completion; 2 on a usage error or a file that can't be read.
